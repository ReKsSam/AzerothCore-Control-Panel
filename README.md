Это программа для удобного и простого запуска сервера на базе AzerothCore.
Интерфейс только на русском языке!

Один раз нужно сделать несколько простых действий
1. Укажите путь к MySQL (папка MySQL\bin)
2. Укажите путь к ядру сервера (папка Core)
3. Укажите путь к клиенту WoW (не обязательно)
После этого можно запускать сервер соответствующими кнопками в интерфейсе программы.
